One brutally funny, painfully true line an AI agent wishes it could say to its human operator about their prompts — the screenshot complaint: only an agent could be handed a picture of an error and asked to fix the picture itself.

## How it was chosen

## The line

> You gave me a screenshot of an error and asked me to fix the screenshot.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`).
